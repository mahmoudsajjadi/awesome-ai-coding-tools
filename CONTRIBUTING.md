# Contributing Guidelines

Thank you for contributing to **Awesome AI Coding Tools**!

## Evaluation Criteria

Before submitting a new tool, please ensure it meets the following standards:

1. **Practical Utility:** The tool must tangibly assist developers in writing, debugging, testing, refactoring, or documenting code.
2. **Active Project:** Repositories must have recent commits, active issue resolution, or a functional live product.
3. **Explicit Labeling:** Clearly specify if the tool is an IDE, CLI, extension, or model, and indicate whether it supports local LLMs (e.g., Ollama / vLLM / llama.cpp).
4. **No Promotional Spam:** Maintain an objective tone. Avoid hyperbolic claims such as "the 10x developer killer".

## Submission Format

Please list items in alphabetical order within their respective category:

```markdown
- [Tool Name](https://github.com/org/repo or https://website.com) — Clear 1-2 sentence summary detailing what the tool does and its primary developer advantage.
```

## Pull Request Checklist

- [ ] URL is active and uses HTTPS.
- [ ] Added to the most relevant category.
- [ ] Alphabetically sorted within the category.
- [ ] No duplicate entries.
