📐 The Deterministic VRAM Formula

All memory values shown below are engineering estimates derived from the standardized formula:

Total VRAM ≈ Weight VRAM + KV Cache + 20% Overhead
where Weight VRAM = (Parameters × Bits) / 8 and KV Cache = 2 × Layers × KV Heads × Head Dim × Precision Bytes × Context × Batch Size.

For exact layer counts, GGUF quants (Q4_K_M, Q5_K_M, Q8_0), and context lengths, see the full Hardware & VRAM Sizing Guide.
